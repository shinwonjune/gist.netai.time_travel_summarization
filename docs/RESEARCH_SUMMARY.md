[연구 주제]
시각 언어 모델과 디지털 트윈을 연계해 과거 시공간 탐색 프레임워크 설계·구현

[연구 목적]
관리자의 사건 수동 탐색 부담 감소 및 직관적 파악 지원

[문제 해결 방법]
확장형 프레임워크를 설계·구현하여 사건 중심 요약 제공
- 프레임워크는 시공간 재현 환경(디지털 트윈), 시공간 재구성 로직(Omniverse Extension), 이벤트 탐지(VLM)의 독립 모듈로 구성
- 모듈 간 데이터 입출력 규격을 정의하여 인터페이스 기반으로 연결
- 신규 이벤트 정의 및 모델 교체에 유연하게 대응 가능한 구조 설계
*사건 중심 요약: 특정 사건(예: 충돌)이 발생한 시간과 위치 중심으로 디지털 트윈 렌더링을 재구성해 즉시 이동·상호작용할 수 있는 시공간 요약

[핵심 기여]
- 폐루프 시공간 분석 프레임워크 제안 (디지털 트윈 ↔ VLM)
- 사건 중심 요약 방식 제안
- 디지털 트윈 기반 VLM 성능 향상 실험적 검증

[프레임워크 작동과정 3단계]
1. 선형적 시공간 복원: 디지털 트윈 내 객체의 움직임을 시간축 따라 재현
- VLM이 사건 시점과 관련 객체를 식별할 수 있도록 장면 위에 timestamp와 objectID를 Overlay
2. 자동 탐지: VLM이 영상을 분석해 사용자 정의 사건을 탐지 후 timestamp, 연관된 objectID를 구조화된 형태로 반환
3. 사건 중심 시공간 복원: 도출된 정보를 디지털 트윈에 피드백해 사건 발생 시점과 공간 중심으로 요약 장면을 재구성

[추론 환경 조절 성능 검증 실험]
디지털 트윈의 환경 조절 능력이 VLM 추론의 성능과 효율을 개선할 수 있음을 검증
1. 조절 환경
- 시각적 복잡도: Full / Simplified / Abstract 단계별 시각적 추상화 적용 
- 재생 속도: 3배속, 1배속 재생 속도 적용
2. VLM 성능 평가 메트릭: F1 Score 
3. 실험 결과
- 시각적 복잡도 완화 환경은 더 높은 F1 score를 기록했으며, Qwen3-VL-8B는 Abstract 환경에서 약 0.2 개선
- 3배속 가속 환경은 정확도 저하 없이 추론 시간을 50% 이상 단축했고, 장시간 로그(최대 12시간)에도 적용 가능함을 확인
4. 결론: 디지털 트윈을 활용한 환경 제어를 통해 VLM의 성능과 추론 효율을 동시에 개선할 수 있음을 입증

[플랫폼 인프라 (연구 이후 고도화)]
- 데이터 레이크(minIO): 좌표 로그를 시간 분할 청크 + manifest로 인덱싱, 재생 헤드 주변만
  윈도우 로딩 + 프리페치 → 대규모(최대 12시간) 로그를 경계 stall 없이 무지연 재연.
  로컬(file://)과 오브젝트 스토리지(s3://)를 URI 스킴 어댑터로 동일 코드 경로 처리.
- 이벤트 인덱스: VLM 추론 결과를 시간축 검색 표면(vlm_events/)으로 축적하고, twin time 구간
  조회 → 선택 이벤트 시점으로 트윈 재구성(RAG/agent 단계의 검색 받침).
- VLM LoRA 튜닝: 물리(PhysX) 충돌 시뮬레이션으로 학습 데이터를 생성해 Qwen3-VL-8B를 충돌
  탐지 태스크로 LoRA 미세조정. 데이터 증량에 따른 성능 스케일링(base→v1→v2)을 F1로 실증
  (STRICT F1 0.065→0.503, RELAXED 0.338→0.784). 추론은 vLLM OpenAI 호환 직접 호출.
- 원격 제어면: extension GUI → REST 잡 API → GPU별 순차 큐(생성/학습/서빙 잡 타입,
  서빙 GPU 역할 분리). 서빙과 유한 잡의 자원 경합을 구조로 차단.
